# My Components - React Component Library

A modern, accessible React component library built with TypeScript, Tailwind CSS, and comprehensive testing. Features flexible InputField and DataTable components with full customization options.

## Features

### 🎨 Components

#### InputField
- **Variants**: Outlined, Filled, Ghost
- **Sizes**: Small, Medium, Large
- **Features**: Password toggle, clear button, loading states
- **Accessibility**: ARIA labels, keyboard navigation, screen reader support
- **Validation**: Error states with custom messages

#### DataTable
- **Sorting**: Ascending/descending on sortable columns
- **Selection**: Individual row and select-all functionality
- **Responsive**: Horizontal scroll on mobile devices
- **States**: Loading and empty state handling
- **Accessibility**: ARIA sort attributes, proper table semantics

### 🛠 Technical Stack

- **React 18** with TypeScript
- **Vite** for fast development and building
- **Tailwind CSS** for styling
- **Storybook** for component documentation
- **Vitest** + React Testing Library for testing
- **Lucide React** for icons

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd my-components

# Install dependencies

# Start development server
